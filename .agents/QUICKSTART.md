# Quick Start

## Commands

```bash
bun install
bun run typecheck
bun run test
```

## Workflow

1. Create feature branch
2. Make changes
3. Create changeset: `bun run changeset`
4. Open PR to `main`
5. Merge PR
6. Trigger **Release** workflow from GitHub Actions (`RC` or `Release`)

See `PROJECT-STRUCTURE.md` and `../CONTRIBUTING.md`.
