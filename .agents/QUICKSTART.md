# Quick Start

## Commands

```bash
bun install
bun run typecheck
bun run test
```

## Workflow

1. Create feature branch
2. Make changes
3. Create changeset: `bun run changeset`
4. Open PR to `main`
5. Merge PR
6. Maintainer runs Release workflow (`rc` or `latest`)

See `PROJECT-STRUCTURE.md` for layout and `../CONTRIBUTING.md` for release policy.
